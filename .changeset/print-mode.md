Print mode: the API reference and the developer docs print as a book (cover, title page, contents with page numbers, numbered chapters, tables and figures, references) or as an APA 7 paper. A printer button in the header, `view: "print"` and `print` options, `oaspect print` and `oaspect docs print`. Core adds `flattenSchema()`.
