Developer docs: the viewer shows a folder of Markdown files as a documentation site, one page at a time, with navigation (from `_sidebar.md`/`SUMMARY.md` or the folders), search across pages, "On this page", links between files, previous/next and "Edit this page". Use `oaspect docs build|bundle|serve <dir>`, `Oaspect.docs()`, `<oaspect-docs>` or `<DocsReference>`. Mermaid diagrams (```mermaid blocks) render in docs and in API descriptions, loaded from jsDelivr only when a page has one.
